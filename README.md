# text-invaders
Space Invaders but with text and ascii

## Canvas starter

A minimal canvas sandbox: move the mouse through the text to scatter the letters into a swirling current. Some letters turn pink, then everything gradually returns to its original position and color. Touch dragging works too.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Build with `npm run build`.

The text and motion live in `main.js`; page styling lives in `style.css`. There are no runtime dependencies, controls, or test cases.
