The game ships them locally; it does not request books from Gutenberg at runtime.
`sources.json` records the author, title, and Gutenberg ebook ID of each sample.

Prose line wrapping, emphasis underscores, and illustration captions were removed;
poetry line breaks and the editions’ original wording are preserved. No introductions,
editorial commentary, or ebook boilerplate are used as game text. Quotes are drawn
from these excerpts, with author, title, and a source link displayed in the game.

The Gutenberg editions identify these original works as public domain in the USA.
The [Project Gutenberg License](../public/gutenberg-license.txt) is included in
the repository and copied into production builds as `/gutenberg-license.txt`.
